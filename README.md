
# HR Analytics Dashboard | Power BI

## Project Overview

This project is an interactive HR Analytics Dashboard developed using Power BI to analyze employee demographics, income, performance, experience, and attrition.

The project demonstrates the complete data analysis workflow from data cleaning and transformation to DAX-based analysis and interactive dashboard development.

## Tools & Technologies

- Microsoft Excel
- Power Query
- Power BI
- DAX

## Dataset

The project uses an HR Analytics dataset containing 1,480 employee records.

During data cleaning, 10 duplicate employee records were identified and removed, resulting in 1,470 unique employee records used for the dashboard.

## Data Cleaning

The data was cleaned and transformed using Excel and Power Query.

Key data-cleaning steps included:

- Removed duplicate employee records
- Checked missing values
- Checked and corrected data types
- Removed/checked data errors
- Renamed columns where required
- Applied filtering and sorting
- Validated important HR fields

## Dashboard Features

The dashboard includes:

- Total Employees
- Average Monthly Income
- Attrition Rate
- Average Experience
- Average Performance
- Employees by Department
- Employees by Job Role
- Average Monthly Income by Department
- Attrition Count
- Age Distribution
- Performance Distribution
- Gender Distribution
- Experience vs Monthly Income
- Interactive slicers for Department, Gender, Job Role and OverTime
